# 📱 WebChat SPA

A single-page application simulating a real-time chat interface, entirely client-side rendered with vanilla JavaScript and Tailwind CSS — no external frameworks.

## Features
- **Responsive layout**: mobile-first, fixed sidebar on desktop, bottom navigation + full-screen overlay on mobile
- **SPA navigation**: smooth transitions between views (contact list, 1-to-1 chat, group chat) via Tailwind class toggling
- **Chat module**: interactive 1-to-1 chat with delayed auto-replies; static group chat view
- **Social-style UI**: Stories placeholder, search input (UI ready for future logic)

## Tech Stack
- HTML5 — semantic, SEO-friendly markup
- Tailwind CSS 4 — responsive components, class-based navigation state
- JavaScript — event handling, dynamic DOM creation

## Goal
Build a realistic chat experience without a backend: no page reloads (SPA architecture), mobile-first UX, and simulated 1-to-1 interactivity.

## Run Locally
No build tools required.
```bash
git clone https://github.com/greenexplorerdev/Web-Chat-Application.git
```
Open the folder in VS Code and use the Live Server extension on `index.html`.
